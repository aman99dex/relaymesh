# RelayMesh

An Android messenger that works with no internet, SIM, or server. Phones relay messages to each
other over Bluetooth LE, Wi-Fi Aware/Direct, and optionally LoRa, hopping from device to device
until each message reaches the person it's for.

Status: research. See [RESEARCH.md](RESEARCH.md) for transports, call feasibility, prior art,
and the MVP plan.
